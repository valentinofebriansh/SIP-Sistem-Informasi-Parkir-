# UBParkir (prototype)

Next.js 15 (App Router) + Tailwind v4, tanpa backend. Data = mock di `src/data`, state (login, reservasi, ulasan) di `localStorage`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint    # type-check
```

Akun demo: `mahasiswa@ub.ac.id` / `123456`

Cakupan MoSCoW: Must (info slot, pencarian) · Should (rekomendasi, denah, login/daftar) · Could (ulasan) · Won't (kamera real-time: hanya placeholder "Segera hadir").
